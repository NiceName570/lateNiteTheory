# How this folder works

- Folders 01-06: grouped by method (sound, light, sound+light, sleep, subliminal suggestion, hypnosis/behavior).
- Folder 09: the remaining original patents (RF, microwave, electrical, ultrasound, birds).
- Patent folder name: YEAR_PATENT-NUMBER_INVENTOR-OR-COMPANY_what-it-does.
- Each of the 23 original patents has a summary and a list of every later patent citing it.
- Citing patents in 01-06 were placed by keywords in their titles; check the summary if one looks misfiled.
- Citing patents outside sound/light/sleep/suggestion (hearing aids, watermarking, birds, etc.) have no folder; they are in the master list.
- all-patents_master-list.csv: every patent collected (23 originals + all citing works, all categories). Opens in Excel.
- who-cites-who_citation-map.csv: one row per citation link; filter cited_patent to follow a chain.
- Source: Google Patents, retrieved 2026-10-05.
