# Rife Machine Evidence and Electrical Reconstruction

Evidence-first reconstruction of three deliberately separate device lineages:

1. pre-Crane No. 4;
2. AZ-58 / Crane;
3. Bare / Holland.

Start with [`PROJECT_INDEX.md`](PROJECT_INDEX.md) for the controlling question,
current status, evidence boundaries, and navigation. The append-only chronology
is in [`RIFE_RESEARCH_LOG.md`](RIFE_RESEARCH_LOG.md).

This repository distinguishes primary records, later testimony, assumptions,
and computed results. Electrical simulations and historical claims do not
establish therapeutic efficacy.

Large evidence PDFs, rendered source images, and authoritative LTspice raw
outputs are stored with Git LFS. Temporary renders and downloaded simulator
application binaries are intentionally excluded from Git.
